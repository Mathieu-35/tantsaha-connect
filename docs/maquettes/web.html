Maquettes web — administration

Site réservé aux agronomes / administrateurs. Il sert à tenir à jour les calendriers, les conseils et les voix qui arrivent ensuite sur les téléphones. Cliquez dans la barre latérale du cadre ci-dessous.

Toutes les données affichées sont des exemples inventés (calendriers non validés, chiffres fictifs). Les textes de l'interface sont en français ; les contenus destinés aux paysans (titres, conseils) sont en malagasy, à relire par vous. Cette maquette est pensée pour un écran d'ordinateur (≥ 1100 px).
