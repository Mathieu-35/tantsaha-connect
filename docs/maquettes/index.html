Comment juger ces maquettes

  1. Sans lire. Regardez un écran 3 secondes : devinez-vous à quoi il sert grâce aux images seules ?
  2. Au soleil. Les textes restent-ils lisibles, les boutons assez gros pour un gros doigt ?
  3. Les parcours. Dans « Mobile », faites les 4 tâches : sont-elles évidentes ?
  4. Le malagasy. Corrigez tous les mots qui sonnent faux.
Rouge = danger. Dans les maquettes, le rouge n'apparaît que pour l'alerte d'orage et la suppression. Passez en mode wireframe : une mention « (rouge) » indique où il est utilisé.
